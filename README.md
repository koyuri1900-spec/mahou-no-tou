# VALID

遺伝子がすべてを決める世界で、地上に残された最後の出発ゲートの審査官になる身分審査ゲームです。
いまは試作版(DAY 0〜3)です。PC のブラウザで、マウスを使って遊びます。

**▶ 遊ぶ: https://koyuri1900-spec.github.io/mahou-no-tou/**

HTML・CSS・素の JavaScript だけで動く静的サイトです。ビルド工程も外部サーバーも要りません。

## あらすじ
2089年。地表は人が住めなくなりつつあり、人類は軌道上の居住環〈エリュシオン〉へ移り住んでいる。
移住できるのは、遺伝子が「適格(VALID)」と判定された者だけだ。
あなたはガイア軌道港 第7ゲートの審査官。娘のアイリは心臓の病のリスクで「不適格」と判定されている。
30日後の最終便で、地上のゲートはすべて閉じる。

## 遊び方
1. 朝、窓口に今日の新しい規則と道具が表示される。規則冊子などを確かめてから **【業務開始】** を押す(押すまで時計は止まっている)。
2. 上のホールの **掲示板** をクリック(Space キー)して、次の申請者を呼ぶ。
3. 窓口の下の **受取口** に出された書類を、机の上へドラッグする。書類は手を離した場所に置かれる。
4. **採血の対象者**(乗員と、IDの発行から30日以内の者)には、道具棚の **採血キット** を申請者へドラッグする。返ってきた血液の管を、右上の **遺伝子解析機** へ入れる。
5. 右下の **【照合】**(F キー/右クリック)で照合モードにする。照合できる箇所が明るく残るので、食い違っていそうな2か所を順にクリックする。
   矛盾していれば赤く光り、申請者が言い訳をする。判定が済むと照合モードは自動で閉じる。
6. 右端の **【判定】**(D キー)を引き出して判定を選ぶと、IDの判定印の枠に印が押される。
   - 適格:通す / 不適格:帰らせる
   - 限定:INVALID の地上職員を作業区画だけ通す(仕切りの下、離れた位置にある)
7. 書類を窓の申請者へドラッグして **手渡しで返す** と、申請者は去る。適格なら左の出発口へ、不適格なら右へ帰っていく。
8. 身体や検体の偽装を指摘すると、一部の申請者は暴れだす。そのときだけ机に **【警備を呼ぶ】** が現れ、警備員が駆けつけて連れていく。暴れない偽装者は【不適格】で帰す。
9. 判定や手順を誤ると、何を見落としたかが書かれた **違反切符** が机に届く。読み終えたら窓口の下の「切符入れ」へ。
10. 18:00 にその日の便の打ち上げウィンドウが閉じ、搭乗受付が締め切られる。列に残った人は翌日の便へ振り替えられて解散する。窓口が空いていれば、左下の **【業務終了】** を2回押して早めに切り上げることもできる。夜は家計(家賃・食費・電気代・娘の薬)をやりくりする。借金はできず、払えない費用は払えないまま残る。

規則冊子は窓口の下にあります。つかむとその場で見開きで開き、置いた場所に残ります。左右の中央にある ◀ ▶ でページをめくります。
申請者は窓口の前の計量台に一段上がって向き合います。正面を向いていないあいだは黒い影で描かれます。解析機の【♪ 聴く】で、左耳にIDの署名、右耳に採血の検体を音で聴き比べられます(A=ラ、C=ド、G=ソ、T=シ。食い違うと濁った音になる)。
机に据え付けた装置(解析機など)は、常に書類より上に見えます。
日付と時刻は窓口の下の時計で確かめます。身長は、申請者の背後の目盛りの壁で、頭頂の高さを読みます。
画面はウィンドウいっぱいに広がります。右上の四角いボタンか F11 キーで全画面になります。M キーで音のオン・オフを切り替えます。

| 日 | 増える規則と道具 |
|---|---|
| DAY 1 | ゲノムID(期限・判定・発行日)、身長の壁、地上職員の作業許可証、採血(対象者のみ)と16塩基の照合 |
| DAY 2 | 搭乗券(名義・日付・印章)、心拍モニタと医療記録 |
| DAY 3 | 採血の対象者は毛髪台紙も提出(ルーペで毛根を確認)、計量台、X線依頼票(体重が申告と違う人に撮らせ、写真が書類で届く) |

道具は支給された日から、机や窓口に置き場ごと現れます。ルーペは机の右の収納から取り出し、レンズの下を3倍に拡大して見られます。

## 起動方法
ファイルは相対パスで参照しているので、どこに置いても動きます。

```bash
python3 -m http.server 8000   # → http://localhost:8000/
```

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 入口 |
| `css/style.css` | 画面の拡大とフォント |
| `js/palette.js` | 色の規則(灰色の世界、色を持つのは遺伝子と血だけ)と乱数 |
| `js/gfx.js` | 描画の土台。絵は 480×270、文字は 960×540 のドットで描く |
| `js/audio.js` | 環境音・効果音・曲(すべてブラウザで合成) |
| `js/data.js` | 規則、新聞、手紙、物語の申請者11人 |
| `js/applicant.js` | 申請者の生成と、矛盾・正しい判定の計算 |
| `js/art.js` | 背景、申請者、行列のドット絵 |
| `js/docs.js` | ID、搭乗券などの書類 |
| `js/shift.js` | 審査業務(ドラッグ、照合、判定、時間) |
| `js/screens.js` | タイトル、導入、朝の新聞、夜、終幕 |
| `js/main.js` | 起動、画面の切り替え、入力、保存 |
| `docs/WORKLOG.md` | 作業ログ |

## テスト
```bash
npm test                       # 判定ロジックのテスト(node だけで動く)
npm run test:e2e               # ブラウザで3日間を通しで遊ぶ(Playwright が必要)
```
