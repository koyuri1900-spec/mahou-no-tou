# VALID

遺伝子がすべてを決める世界で、地上に残された最後の出発ゲートの審査官になる身分審査ゲームです。
いまは試作版(DAY 0〜3)です。PC のブラウザで、マウスを使って遊びます。

**▶ 遊ぶ: https://koyuri1900-spec.github.io/mahou-no-tou/**

HTML・CSS・素の JavaScript だけで動く静的サイトです。ビルド工程も外部サーバーも要りません。

## あらすじ
2089年。地表は人が住めなくなりつつあり、人類は軌道上の居住環〈エリュシオン〉へ移り住んでいる。
移住できるのは、遺伝子が「適格(VALID)」と判定された者だけだ。
あなたはガイア軌道港 第7ゲートの審査官。娘のアイリは心臓の病のリスクで「不適格」と判定されている。
30日後の最終便で、地上のゲートはすべて閉じる。

## 遊び方
1. 窓口の横の **【呼出】**(Space キー)で申請者を呼ぶ。
2. **受取口** に出された書類を、机の上へドラッグする。
3. 道具棚の **採血キット** を受取口へドラッグすると、血液の管が返ってくる。管を右上の **遺伝子解析機** へ入れる。
4. **【照合】**(F キー/右クリック)で照合モードにし、食い違っていそうな2つの欄を順にクリックする。
   矛盾していれば赤く光り、申請者が言い訳をする。
5. 右下の **【判定】**(D キー)を開き、判定を選ぶ。
   - 適格:通す / 限定:INVALID の地上職員を作業区画だけ通す / 不適格:帰らせる
   - 拘束:身体や検体の偽装を照合で指摘できたときだけ使える
6. 書類をすべて受取口へ戻すと、申請者は去る。
7. 18:00 で業務終了。夜は家計(家賃・食費・電気代・娘の薬)をやりくりする。

規則は机の左下の **規則冊子** にあります。机に置くと開き、ページを切り替えられます。
身長は、申請者の背後の目盛りの壁で読みます。M キーで音のオン・オフを切り替えます。

| 日 | 増える規則と道具 |
|---|---|
| DAY 1 | ゲノムID(期限・判定)、採血と16塩基の照合、身長の壁、地上職員の作業許可証 |
| DAY 2 | 搭乗券(名義・日付・印章)、心拍モニタと医療記録 |
| DAY 3 | 毛髪キットとルーペ(毛根)、計量台(申告質量)、X線 |

## 起動方法
ファイルは相対パスで参照しているので、どこに置いても動きます。

```bash
python3 -m http.server 8000   # → http://localhost:8000/
```

## ファイル構成
| ファイル | 内容 |
|---|---|
| `index.html` | 入口 |
| `css/style.css` | 画面の拡大(整数倍)とフォント |
| `js/palette.js` | 色の規則(灰色の世界、色を持つのは遺伝子と血だけ)と乱数 |
| `js/gfx.js` | 描画の土台。絵は 480×270、文字は 960×540 のドットで描く |
| `js/audio.js` | 環境音・効果音・曲(すべてブラウザで合成) |
| `js/data.js` | 規則、新聞、手紙、物語の申請者11人 |
| `js/applicant.js` | 申請者の生成と、矛盾・正しい判定の計算 |
| `js/art.js` | 背景、申請者、行列のドット絵 |
| `js/docs.js` | ID、搭乗券などの書類 |
| `js/shift.js` | 審査業務(ドラッグ、照合、判定、時間) |
| `js/screens.js` | タイトル、導入、朝の新聞、夜、終幕 |
| `js/main.js` | 起動、画面の切り替え、入力、保存 |
| `docs/WORKLOG.md` | 作業ログ |
