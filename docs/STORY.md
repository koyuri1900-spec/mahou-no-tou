# VALID 物語設計(草案)

> 本編の物語を決めるための文書です。「決定」「保留」「案」を分けて書きます。

## 決定

### 世界と主題
- 2089年。人類は軌道上の居住環〈エリュシオン〉へ移り住んでいる。移れるのは遺伝子が「適格(VALID)」の者だけ。
- 舞台はガイア軌道港 第7ゲート。地上に残った最後の出発ゲート。
- **はじめは最終便の日付が決まっていない**。21日目のステーションの爆破をきっかけに、上層部が地球との決別を決め、30日目(05.30)が最終便の日に決まる。
- **上層部の本当の狙い(裏の設定)**:居住環に住める人数が決まっているので、選別をしているだけ。はじめは選民思想ではない。
- **陰謀論の始まりは一本の新聞記事**:ある記者は、前から人々を煽る記事をたびたび書いている(1日目の新聞から署名記事が載る)。その記者が「上層部は定員を口実に選民を行っている」と書いた記事で、ついに国民同士の衝突が始まる。これが最初の転換点。
  - 煽られた国民と、地球の上層部も衝突しはじめる。新聞の上では互いに否定し合うが、感情はどんどん膨れ上がっていく。
  - この衝突の中で分派が生まれる。上層部が選民を始めたのが先か、分派(と煽られた国民)が先かは、あいまいにしてよい。
  - 表立って語らない。主人公は申請者の証言や、窓口に残された物証から「どうやらそういうものを目指しているらしい」と受け取る。プレイヤーにも断定はさせない。
- **「地球は本当はまだ住める」という説も、作中の陰謀論の一つ**。本当かどうかは示さない。

### 主人公とアイリ
- 主人公は第7ゲートの審査官(VALID の地上職員)。
- 娘のアイリ(8歳)は INVALID。心臓の病を抱えている。
- 医者からは「地上の治療では延命にしかならない。軌道上の医療施設へ」と勧められる。しかしアイリは INVALID なので宇宙へ行けず、お金も生活費で消えていく。
- 必要なお金は **渡航費用と治療費の合算**。症状は悪くなり、費用は増える一方。
- アイリの手紙は、はじめは父を応援する内容。だんだん現実離れした言葉が混ざり、病が進んでいる証になる。

### ハロウ
- 毎朝窓口を通るエリートの航法士で、主人公に良くしてくれる。味のある常連の人物。三人のハロウ案は不採用。
- 本当は INVALID。かつて組織を利用して「ジェイ・ハロウ」という人物になり、いまは組織に属している。プレイヤーには完全には明かさず、暗に示す。
- **殺される上司の部下でもあり、移民を送り届ける実行役**。
- **影の英雄**:最初の場面から、新聞や職員同士の会話で「正体不明の男が移民を手伝っている」という噂が出る。当局はその男を探っている。それがハロウだとは明かさない。
- 終盤(最終日でなくてよい)、臨時の検査に引っかかる。
- 本筋との結びつきは、下の案の2・3・4を検討する。

### 内部の事件
- 映画『ガタカ』を下敷きにする。日中の業務時間中に起きる(「事件の日」)。
- **殺されるのは主人公の上司**。上司は組織の本体と上層部をつなぐ人物で、事件の前から主人公に「この人を通してほしい」「ここは見なかったことに」と頼みごとをしてくる。
- 頼みごとの見返りは**チップ**。後ろめたさを感じさせない。主人公と上司の会話は、犯罪に手を染めているというより「善いことのためにやっている」という空気で進む。
- 現場に残るのはハロウの毛。毛から出た手配書は、**ハロウという人物になる前の記録**に一致する。主人公はいくら検査をしてもハロウにはたどり着けないが、ハロウがその人物であるような手がかりは間接的に示す。
- ハロウは重要参考人だが、事件とは無関係。
- **殺害は地球のトップ(地球連邦の上層部)が決めたこと**という形にする。個別の犯人の人物は作らない(人物を増やさない)。
- **事件はあくまで新聞の上で起きたこと**。主人公はあまり関心を持たず、事実として事件があったことを知っていればよい。真犯人を捕まえる仕組みは作らない。事件はそこで終わり、話は過激な分派の話へ移っていく。
- **ノード記者**:人々を煽る記事を書き続けてきた記者。終盤、自分も宇宙へ逃げようとして窓口に現れる。

### 組織
- **本体**:不法移民を居住環へ送り届ける組織(援助組織でもあり、犯罪組織でもある)。主人公とは、上司を通して早い段階から取引をする関係。
- 本体は地球の上層部とつながっていた(そのつなぎ役が上司)。そのつながりが、分派が生まれるきっかけになる。
- **事件のあと、仮面の男が「担当は私に変わった」と窓口に近づいてくる**。2日目の封筒の男はいったん消す。
- **分派**:後半、遺伝至上主義そのものを壊そうとする過激な分派が生まれ、テロに走る(暗殺の指示、工作員を通させる、など)。
- 仮面の男は名前を出さない。サイ・マロという人物は削除する。仮面の男が本体の後任なのか、分派の人間なのかは、要求が重くなるにつれて見えてくる。
- 遺伝子情報を流す手段:仮面の男が窓口に現れ、特定の人物の情報を流すよう求め、機械を渡していく。

### 30日の大きな出来事
- **DAY 19 前後**:分派が内部の事件の真相をビラで暴露し、デモが一気に過激になる。
- **DAY 21 前後**:**移民先のステーションが爆破される**(分派のテロ)。これが二つ目の転換点。上層部は地球との決別を決め、30日目を最終便の日にする。ここから上層部は手段を選ばなくなる(選民による選別など)。
- 新聞記事(最初の転換点)は、もう少し早い段階に出す。

### 遊びと家計
- 業務は3〜4日ごとに増える(要調整)。
- 罰金は常に同じ(いまの仕組みのまま)。
- 借金の仕組みは作らない。払えない費用が出た(借金に入る)時点で、結末に入る。
- 手帳は入れない。
- 地球が見捨てられていく様子は、遊びの中で悲惨な方向に盛り上げる(家計、規則、デモから暴力へ)。

### 結末(決まっているもの)
- 借金に入り、アイリが死ぬ。主人公も後を追う。
- アイリだけが宇宙へ行ける。
- 主人公も宇宙へ行ける。
- ほかの結末は、後でまとめて考える。
