# VALID 物語設計(草案)

> 本編の物語を決めるための文書です。「決定」「保留」「案」を分けて書きます。

## 決定

### 世界と主題
- 2089年。人類は軌道上の居住環〈エリュシオン〉へ移り住んでいる。移れるのは遺伝子が「適格(VALID)」の者だけ。
- 舞台はガイア軌道港 第7ゲート。地上に残った最後の出発ゲートで、30日後(05.30)の第12便が最終便。
- **上層部の本当の狙い(裏の設定)**:居住環に住める人数が決まっているので、選別をしているだけ。はじめは選民思想ではない。
- **陰謀論が後から現実になる**:「上は選ばれた者だけの新しい人類を作り、地球を見捨てる気だ」という陰謀論が広まり、活動が過激になる。追い詰められた上層部が強硬になり、陰謀論の言っていたことが後から現実になっていく。
  - 表立って語らない。主人公は申請者の証言や、窓口に残された物証から「どうやらそういうものを目指しているらしい」と受け取る。プレイヤーにも断定はさせない。
- **「地球は本当はまだ住める」という説も、作中の陰謀論の一つ**。本当かどうかは示さない。

### 主人公とアイリ
- 主人公は第7ゲートの審査官(VALID の地上職員)。
- 娘のアイリ(8歳)は INVALID。心臓の病を抱えている。
- 医者からは「地上の治療では延命にしかならない。軌道上の医療施設へ」と勧められる。しかしアイリは INVALID なので宇宙へ行けず、お金も生活費で消えていく。
- 必要なお金は **渡航費用と治療費の合算**。症状は悪くなり、費用は増える一方。
- アイリの手紙は、はじめは父を応援する内容。だんだん現実離れした言葉が混ざり、病が進んでいる証になる。

### ハロウ
- 毎朝窓口を通るエリートの航法士で、主人公に良くしてくれる。味のある常連の人物。三人のハロウ案は不採用。
- 本当は INVALID。かつて組織を利用して「ジェイ・ハロウ」という人物になり、いまは組織に属している。プレイヤーには完全には明かさず、暗に示す。
- 終盤(最終日でなくてよい)、臨時の検査に引っかかる。

### 内部の事件
- 映画『ガタカ』を下敷きにする。日中の業務時間中に起きる(「事件の日」)。
- 現場に残るのはハロウの毛。毛から出た手配書は、**ハロウという人物になる前の記録**に一致する。主人公はいくら検査をしてもハロウにはたどり着けないが、ハロウがその人物であるような手がかりは間接的に示す。
- ハロウは重要参考人だが、事件とは無関係。
- 真犯人は選民思想派。主人公が窓口の道具で証拠を集め、捕まえる機会を得る。この事件に、選民思想派との対決を組み込む。

### 組織
- **本体**:不法移民を居住環へ送り届ける組織(援助組織でもあり、犯罪組織でもある)。主人公とは早い段階から取引をする関係。
- 本体は地球の上層部とつながっていた。そのつながりが、分派が生まれるきっかけになる。
- **分派**:後半、遺伝至上主義そのものを壊そうとする過激な分派が生まれ、テロに走る(暗殺の指示、工作員を通させる、など)。
- 分派の側の人物は**仮面の男**(名前は出さない)。サイ・マロという人物は削除する。
- 遺伝子情報を流す手段:仮面の男が窓口に現れ、特定の人物の情報を流すよう求め、機械を渡していく。

### 30日の大きな出来事
- **DAY 19 前後**:分派が内部の事件の真相をビラで暴露し、デモが一気に過激になる。
- **DAY 21 前後**:**移民先のステーションが爆破される**(分派のテロ)。

### 遊びと家計
- 業務は3〜4日ごとに増える(要調整)。
- 罰金は常に同じ(いまの仕組みのまま)。
- 借金の仕組みは作らない。払えない費用が出た(借金に入る)時点で、結末に入る。
- 手帳は入れない。
- 地球が見捨てられていく様子は、遊びの中で悲惨な方向に盛り上げる(家計、規則、デモから暴力へ)。

### 結末(決まっているもの)
- 借金に入り、アイリが死ぬ。主人公も後を追う。
- アイリだけが宇宙へ行ける。
- 主人公も宇宙へ行ける。
- ほかの結末は、後でまとめて考える。

## 保留

- **本体と分派の境目**:主人公の取引相手が、分派になってからも同じ人物か、別の人物に替わるか(下の案)。
- **ハロウと本筋の結びつき**:もっと強くしたい(下の案)。
- **組織と分派の名前**(下の案)。
- **主人公自身が宇宙へ行く道**。
- **物価と薬代の上がり方**。

## 案

### 勢力の図
| 勢力 | 立場 | 人物 |
|---|---|---|
| 上層部の穏健派 | 最終便の席の見直し(INVALID にも席を)を探る。裏で本体とつながっている | 第12便の移住責任者(内部の事件の被害者) |
| 上層部の選民思想派 | 点数の高い者だけで最終便を飛ばしたい | 第12便の飛行責任者(真犯人)、監察官 |
| 組織の本体 | 不法移民を居住環へ送り届ける | 本体の窓口役(初期の取引相手)、ハロウ |
| 組織の分派 | 遺伝至上主義の仕組みそのものを壊す | 仮面の男 |

### 本体と分派の境目
- 本体の上層部とのつながりは、穏健派の移住責任者だった。席の見直しも、本体の「上へ送る」仕事も、この人に支えられていた。
- 内部の事件で責任者が殺され、本体は上とのつながりを失う。本体の一部が「話し合いでは何も変わらない」と見限り、分派になる。
- **取引相手の切り替え(案)**:
  - 第1〜2幕は、本体の窓口役(2日目に封筒を置いていく男)と取引する。求められるのは、人を通すことが中心。
  - 内部の事件のあと、窓口役は姿を消す。代わりに仮面の男が現れる。
  - 仮面の男が、窓口役と同じ人物なのか、窓口役を消した者なのかは、最後まで明かさない(声や癖など、似ている手がかりだけ置く)。

### ハロウを暗に示す手がかり
- 毛から出た手配書は、十数年前に「死亡」と届けられた人物の古い記録に一致する。監察官は「死人の毛が落ちていた」と首をかしげる。
- 手配書の古い写真は少年のころのもの。瞳の色と、左利きの記録が、ハロウと同じ。
- 事件の日、ハロウは窓口で何気なく「責任者に会ってきた」と話している。
- 誰も断定しない。二つを結びつけられるのはプレイヤーだけ。

### 真犯人を捕まえる証拠
1. **当局の掲示**:死亡推定時刻と、「被害者ともみ合った形跡。犯人は右手を負傷している可能性」。
2. **入構記録**:飛行責任者が、事件の時刻に管制区画へ入った記録。本人は「その日は一日、発射台にいた」と話す。
3. **X線**:飛行責任者の右手の骨に、新しいひび。
- 食い違いを照合で指摘すれば拘束できる。気づかなければ、飛行責任者は最終便で飛ぶ。
- 捕まえると、選民思想派が主人公に圧力をかける(監察官の締め付け、「娘は無理だが、あなた一人の席なら用意する」という取引)。

### 移民先のステーションの爆破が転換点になる理由
- 上層部の狙いは「定員があるから選別する」だけだった。
- 爆破で受け入れ先の一部が失われ、定員そのものが減る。
- 減った席をめぐって、選民思想派の「点数の高い者だけを」が現実の方針になる。陰謀論が言っていたことが、テロによって現実になる。
- 主人公が飛行責任者を捕まえていれば、選民思想派の主導権が弱まり、強硬策の一部が遅れる(結末に響く)。

### ハロウを本筋に強く結びつける案
1. **アイリの道**:ハロウは最終便の航法士。アイリを上へ送る道の一つが「航法士の私物区画にひそかに乗せる」になる。ハロウが臨時の検査に捕まれば、その道が閉じる。
2. **仮面の男との対立**:仮面の男はハロウに、乗員の立場で爆発物を上へ運ばせようとする。ハロウは断る。仮面の男は報復に「乗員の中に INVALID がいる」と当局へ通報し、それが臨時の検査のきっかけになる。
3. **ハロウの過去**:ハロウには、アイリと同じ心臓の病で地上で死んだ妹がいた。ハロウがアイリを気にかける理由になる。
4. **主人公の選択がハロウの運命に響く**:仮面の男の要求に応じていたかどうかで、通報の時期や、ハロウが逃げ延びられるかが変わる。
