# VALID 物語設計(草案)

> この文書は、本編の物語を決めるためのたたき台です。決まったことは「決定」、相談中のことは「案」と書きます。

## 前提(決定)
- 2089年。地表は住めなくなりつつあり、人類は軌道上の居住環〈エリュシオン〉へ移る。移れるのは遺伝子が「適格(VALID)」の者だけ。
- 舞台はガイア軌道港 第7ゲート。地上に残った最後の出発ゲートで、30日後(05.30)の第12便が最終便。
- 主人公は第7ゲートの審査官(VALID の地上職員)。娘のアイリ(8歳)は心臓の病のリスクで「不適格」と判定されている。この診断は、実は会社に偽られたもの。
- ハロウは毎朝窓口を通るエリートの航法士。最終日に当局が臨時の生体検査を行い、ハロウはそこで捕まりかける(映画『ガタカ』の筋)。三人のハロウ案は不採用。
- 試作版(DAY 1〜3)では登録簿は正しい。登録簿そのものを疑う展開は中盤から。

## 3つの筋と、そのつながり
| 筋 | 中身 | ほかの筋とのつながり |
|---|---|---|
| ハロウ(主軸) | 毎朝通る航法士。最終日の臨時の生体検査 | ハロウを偽装に仕立てたのは〈梯子〉。〈梯子〉を通報すればハロウも暴かれる |
| 〈梯子〉 | 判定端末が読んだカードの遺伝子情報を流せと持ちかける | 見返りは「アイリの登録簿を書き換えて VALID にする」。登録簿の書き換えが、中盤の「登録簿も疑う」の正体 |
| 事件とアイリ | 管制区画で航法責任者が死ぬ。手配書が出る | 死んだ責任者は、ヘリックス社の診断の偽りを暴こうとしていた。真犯人を捕まえれば、アイリの診断を正しく直す道が開く |

ハロウの話は主軸のままで、〈梯子〉と事件の筋は、どちらも最終日のハロウの場面で一つに合流する。

## 新しい仕組み(物語に必要なもの)
- **塩基の手配書**:現場の痕跡から読めた塩基を一部だけ載せる手配書(例:3番目=G、7番目=T、12番目=A)。登録簿に顔のある人は「顔写真の手配書」で手配される。
- **血縁の照合**:遺伝子が半分ほど一致すれば親子・きょうだい。ふだんの業務では「同伴する子どもは親と血縁であること」(人さらいを止める)として使う。
- **遺伝子情報を流す**:判定端末にカードを置いたとき、〈梯子〉に情報を流すかどうかを選べる(夜の家計に入る)。流した情報は、別の誰かの偽装に使われる。
- **登録簿の更新履歴**(中盤):記録の欄に「登録簿の最終更新」が出る。最近書き換えられた登録簿は疑う。

## 30日の流れ
### 第1幕 仕事を覚える(DAY 1〜7)
- DAY 1〜3 は試作版の内容。ハロウは2日目から毎朝通る。
- DAY 2:サイ・マロが封筒を置いていく(〈梯子〉の最初の接触。受け取るかどうかが記録される)。
- DAY 3:ノラが兄カイのことを尋ねる。
- DAY 4:血縁の照合が始まる(家族連れ、同伴の子ども)。
- DAY 6:夜の手紙に〈梯子〉から最初の頼み。「今日の端末の読み取りを1件だけ」。
- 新聞では〈梯子〉の摘発記事と、〈梯子〉に救われた家族の投書が交互に載る。

### 第2幕 登録簿を疑う(DAY 8〜18)
- DAY 8:登録簿が書き換えられた申請者が初めて現れる(更新履歴の仕組みが始まる)。
- DAY 10:〈梯子〉がアイリの診断記録の写しを送ってくる。診断の数値が偽られている。
- DAY 12:管制区画で、第12便の航法責任者が死ぬ。
- DAY 13:現場のまつ毛から塩基の手配書が出る。乗員の採血が毎日になる。
- DAY 14:監察官ダリオがゲートに立つ。ダリオ自身も採血を受ける。その塩基が手配書と半分ほど一致する。手配犯はダリオの血縁者。
- DAY 16:ダリオが「兄は昔死んだ。INVALID に生まれた兄だった」と話す。
- 毎朝のハロウは、ダリオの前で少しずつ追い詰められていく。

### 第3幕 選ぶ(DAY 19〜29)
- DAY 20:ハロウの体重が申告と違う日がある。X線を撮れば、前腕の血液パッドが写る。あなたはハロウが偽装者だと知る(撮らずに通すこともできる)。
- DAY 22:〈梯子〉が取引を持ちかける。「最終便までに情報を流し続ければ、アイリの登録簿を VALID に書き換える」。
- DAY 24:顔写真の手配書が出る(ヘリックス社のオルセン主任。別人の登録簿で最終便に紛れ込もうとしている)。
- DAY 27:オルセンが窓口に来る。捕まえれば、事件の真相とヘリックス社の診断の偽りが表に出る。
- DAY 29:ハロウが窓口で一言だけ話す(あなたが何を知っているかで台詞が変わる)。

### 最終日(DAY 30)
- 当局の臨時の生体検査。最終便の乗員も、その場で新しい検体を出す。
- ハロウが最後に来る。あなたが見逃すかどうかで、ハロウは飛ぶか、止まる。
- アイリは窓口に来るのか(正しい診断で、書き換えた登録簿で、あるいは来ない)。

## 結末(案)
| 結末 | 条件 | 中身 |
|---|---|---|
| 正しい道 | オルセンを捕まえ、ハロウを見逃し、〈梯子〉を拒む | ヘリックス社の偽りが暴かれ、アイリは正しい診断で VALID に。ハロウも飛ぶ。最終便を見送るのは、あなただけ |
| 梯子 | 〈梯子〉に情報を流し続ける | アイリは書き換えた登録簿で飛ぶ。あなたが流した情報で、別の誰かが偽装している |
| 規則の番人 | すべてを規則どおりに処理する | ハロウは拘束、〈梯子〉は摘発。あなたは表彰されるが、アイリは地上に残る |
| 共倒れ | 〈梯子〉に協力したことが監察官に知られる | あなたが拘束される |

## 決めたいこと
1. 監察官ダリオを、ハロウの実の弟にする。
2. 〈梯子〉の正体は最後まで断定しない。それとも、ルートによって正体がはっきり分かれる。
3. 事件の真犯人をヘリックス社の保安主任にし、アイリの診断の偽りと結びつける。
4. 主人公は最後にアイリと一緒に飛べるのか(主人公は VALID だが、地上職員)。
5. 試作版の3日間に、〈梯子〉の予兆をどこまで入れるか(例:2日目の封筒の男を〈梯子〉の使いにする)。
